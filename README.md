# Project 1 – HTML and CSS

## About

This is one of my projects from the ICSI301 Web Application Development course at the National University of Mongolia.

The project is a simple web page made with HTML and CSS. It contains six blocks labeled A to F. I used this project to practice different ways of arranging elements and styling a web page.

## Technologies

- HTML
- CSS

## What I Did

I created the page structure with HTML and used CSS to work on its layout and appearance.

While working on it, I practiced:

- Arranging elements with Flexbox.
- Using inline-block for layout.
- Adding hover effects.
- Working with CSS transitions and animations.
- Applying colors, borders, gradients, and shadows.

## Project Files

```text
ICSI301_Project1/
├── index.html
├── styleA.css
├── styleB.css
├── styleC.css
└── README.md
```

## CSS Styles

I created three stylesheets to try different ways of styling the same page.

- **styleA.css:** Uses Flexbox to arrange the six blocks vertically.
- **styleB.css:** Uses inline-block, hover effects, and fixed positioning.
- **styleC.css:** Includes transitions, gradients, shadows, and animations.

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. To see the other styles, change the CSS file linked in `index.html` to `styleB.css` or `styleC.css`.

## What I Learned

This project gave me a chance to practice the basics of HTML and CSS. 
I became more familiar with different layout methods and learned how to use CSS to change the look and behavior of web page elements.
